# 행사 진행 현황판

깃허브 저장소의 `data.json` 파일이 곧 데이터베이스입니다.
수정할 때마다 커밋이 하나 생기므로, **모든 변경이 영구히 기록되고 언제든 되돌릴 수 있습니다.**

- 열람: 누구나 (토큰 불필요)
- 수정: 저장소 쓰기 권한을 가진 사람만

---

## 설치 (한 번만)

### 1. 파일 올리기

저장소 최상위에 두 파일을 올립니다.

```
index.html
data.json
```

이미 쓰던 파일이 있으면 `index.html`만 교체하고, `data.json`은 아래 3번을 보세요.

### 2. GitHub Pages 켜기

저장소 → Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save

1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 으로 접속됩니다.
이 주소를 팀원들에게 알려주면 됩니다. 팀원은 아무 설정 없이 바로 볼 수 있습니다.

### 3. 기존에 입력해 둔 내용이 있다면

예전 화면에서 `백업 내려받기`로 받아둔 `.json` 파일이 있으면,
관리자로 로그인한 뒤 상단 `백업 불러오기` → 파일 선택 → `지금 저장(커밋)` 을 누르세요.
그러면 그 내용이 `data.json`으로 올라갑니다.

백업 파일이 없다면 `data.json`을 그대로 두고 새로 입력하시면 됩니다.

---

## 관리자 토큰 만들기 (관리자 각자 한 번씩)

1. GitHub → 우측 상단 프로필 → **Settings**
2. 좌측 맨 아래 **Developer settings**
3. **Personal access tokens → Fine-grained tokens** → `Generate new token`
4. 아래처럼 설정합니다.

   | 항목 | 값 |
   |---|---|
   | Token name | `행사현황판` |
   | Expiration | 행사 종료 후 날짜 (예: 90일) |
   | Repository access | **Only select repositories** → 이 저장소 하나만 |
   | Permissions → Repository permissions → **Contents** | **Read and write** |

5. `Generate token` → 화면에 나온 `github_pat_...` 값을 복사
6. 현황판 접속 → 우측 상단 `관리자 로그인` → 붙여넣기

토큰은 그 사람의 브라우저에만 저장되고 저장소에는 올라가지 않습니다.
공용 PC에서는 작업 후 `편집 중 · 나가기`를 눌러 지워주세요.
토큰을 잃어버렸거나 유출이 의심되면 GitHub 설정에서 삭제(Revoke)하고 새로 만들면 됩니다.

관리자가 2~3명이면 각자 자기 토큰을 만들어 쓰면 됩니다. 저장소 협업자(Collaborator)로 추가되어 있어야 합니다.

---

## 쓰는 법

- 상태 칩을 누르면 `대기 → 진행중 → 완료 → 이슈` 순으로 바뀝니다.
- 바꾸면 상단에 **저장 안 된 변경 있음**이 뜹니다. `지금 저장(커밋)`을 누르면 저장소에 반영됩니다.
- 깜빡해도 30초 뒤 자동 저장되고, 그 전에 창을 닫으려 하면 경고가 뜹니다.
- 저장 전에 브라우저가 꺼져도 초안이 남아, 다음에 열면 "이어서 작업할까요?"라고 묻습니다.
- `변경 기록`에서 지난 커밋 목록을 보고 **어느 시점으로든 되돌릴 수 있습니다.**
- 두 사람이 동시에 고쳐 충돌하면, 덮어쓸지 최신을 받을지 선택창이 뜹니다. 어느 쪽을 골라도 상대 내용은 기록에 남습니다.

## 주의

**저장소가 공개(Public)이면 `data.json` 내용은 인터넷에 공개됩니다.**
참가자 연락처, 계약 금액, 내부 인사 정보 등은 적지 마세요.
가려야 할 내용이 있으면 저장소를 비공개로 바꾸세요. 다만 비공개 저장소의 Pages는 GitHub 유료 플랜에서만 동작합니다.
